# Quiz answers

1. `textContent` sets text. `innerHTML` parses markup, so a message that contains tags becomes HTML.
2. An input a parent passes into a child component. The child reads it and does not reassign the parent's object.
3. `ref` (or `reactive` for an object). In script you read `ref` through `.value`.
4. Two booleans can both be true. One status has one meaning.
5. `code`, `severity`, and `message`. Not the IP or the raw event.
